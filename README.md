# ITS AYUSH — Premium Black & Gold UI

This build keeps the existing HTML/CSS/JavaScript architecture and Firebase lead flow while adding a complete premium black/charcoal/champagne-gold visual system.

## Included
- Premium responsive UI refresh
- Clickable logo and navigation
- Direct email and Telegram contact actions
- GitHub / LinkedIn / YouTube / Instagram / Telegram links preserved
- Clickable portfolio cards using their existing `data-link` destinations
- Portfolio filtering and project details modal preserved
- Service cards route visitors to the enquiry form
- Floating quick-contact rail
- Premium mobile styling
- Gold accent system and glass surfaces
- Reduced-motion support
- Existing Firebase Firestore lead flow preserved
- Existing project content and URLs preserved

## Deploy
Upload the contents of `Its-ayush-main` to GitHub and deploy the repository with Vercel. The project remains a static HTML/CSS/JS site and does not require a build command.
